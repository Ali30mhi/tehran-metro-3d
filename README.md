# 🚇 Tehran Metro 3D

نمایش سه‌بعدی و تعاملی شبکه‌ی مترو تهران با Three.js

## اجرا

    npm install
    npm run fetch-data
    npm run dev

## تکنولوژی‌ها
- Three.js
- Vite
- OpenStreetMap (Overpass API)
